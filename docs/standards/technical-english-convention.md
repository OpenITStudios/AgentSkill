# OpenITStudios Technical English Convention

**Decision:** English is **mandatory for all new technical content** authored through the OpenITStudios ChatGPT GitHub workspace. This rule was requested explicitly on 2026-11-14. It is documented as a workspace convention rather than a silent rewrite of previously adopted shared root policies.

**Scope:** This convention covers current ChatGPT Project instructions, repository work artifacts, and future authorized technical edits. It is NOT a new agent, translation service, release policy, or automatic modification of eleven downstream repositories.

## Required English content

Write new **technical discussions, explanations, architecture, designs, implementation plans, requirements, audit reports, risk assessments, agent instructions, Skills, README/documentation, schemas, diagrams, tables, test cases, benchmarks, evidence labels, status headings, issue/PR descriptions, commit messages, code comments, and technical handoffs** in English. Use concise active sentences, stable concepts, reliable source attribution, and explicit proof limits. Follow ASD-STE100 **clarity principles only** (adapted, not certified) and ISO 24495-1 plain language.

## Preservation and legitimate exceptions

- Preserve exact code identifiers, package and repository names, branches, filenames, commands, API fields, external quotations, source documents, and approved branding without gratuitous translation.
- Do **not** silently rewrite an existing localized product UI, end-user transcript, legal/regulatory source quote, multilingual dataset, customer-facing copy, or accepted language contract.
- Normal nontechnical user conversation may follow the user's language (Indonesian by default). **Technical substance within this ChatGPT Project remains in English**, including technical answers requested in Indonesian, unless a higher-priority instruction or a specifically authorized localized artifact requires another language.
- Approved end-user translations are separate from the canonical English technical explanation or specification. Keep the target audience and language explicit; do not modify the original technical source without permission.

## Source ownership, rollout and proof

This file is the English-language owner for the [ChatGPT Project workspace template](../templates/chatgpt-project-workspace-instructions.md). The [account Custom Instructions](../templates/chatgpt-custom-instructions.md) remain a separate approved historical template. Neither this file nor the project template changes the byte-identical portable AgentSkill core or automatically applies to other repository hosts.

Any downstream policy/source change still requires that repository's selected branch, current source, permission and privacy checks. No mass file translation, Skill replacement, CI/test execution, native proof, version bump, or private-document publication is authorized by this convention. Actual Project Instructions installation and host behavior are **NOT_VERIFIED** until observed.
