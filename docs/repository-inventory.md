## Naming and ownership

- **Category** uses exactly the three approved labels: `Minecraft Development`, `Work & Productivity`, and `Other Projects`. No mandatory subcategories or product-family hierarchy.
- **Product display name** is a human-readable label for this inventory. It does not rename the GitHub repository, executable, package, application identity, import paths, or product branding.
- **Repository** is the exact GitHub source identity for the public entries above. A display name never substitutes for the correct selected branch, HEAD, and local instructions.
- **Purpose** describes the intended function at source level, not tested completion, deployment, live host behavior, or release readiness.
- **Ownership boundary:** AgentSkill maintains shared standards and this public navigation view. It does **not** manage or automatically modify the listed repositories; each repository's local `AGENTS.md`, `GITHUB_RULES.md`, `.agent-standard/profile.json`, `.agent-standard/project-policy.md`, domain Skills, and user permissions remain authoritative.

## Privacy and maintenance

This is a **dated snapshot**, not a live automatically synchronized inventory. Before a deliberate revision, recheck the real repository visibility and product purpose from the selected source. Publicize a repository identity only when public visibility and publication scope are confirmed; a visibility change must not cause an unreviewed private entry to appear. Keep private names, links, branch/commit details, and private project data out of this public repository, README, issues, and commit history.

Maintain the complete eleven-repository inventory **only in a separately authorized, access-controlled destination**. Do not invent a destination, create a private registry or cross-repository automation, or turn this document into a second source of project truth. Updates to a project's product status, Skill routing, CI/testing holds, or release approval remain owned by that project.

The [controlled adoption guide](adoption.md) and [dated source-adoption audit](research/m-repository-agentskill-source-audit-2026-11-14.md) describe AgentSkill distribution and proof limits separately. An inventory entry is **not** proof that the target agent host loaded its instructions or that product tests were executed.
